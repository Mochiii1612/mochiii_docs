Type `/` in either client to see its commands, and keep typing to narrow the list; this page lists them all and says which client has each.

*Describes terminal app 1.6.1 and VS Code extension 1.0.2, which works with terminal app 1.6.1 or later.*

A command that needs more text prints its usage when you type it alone. A `/word` on its own that a client does not know is answered there and not sent to the model; followed by more text, it is sent as a question. The terminal app's keys are in the [Terminal app guide](/using/terminal#keys).

## Chat and history

| Command | What it does | Terminal | VS Code |
|---|---|:---:|:---:|
| `/help` | Lists the commands (the terminal app lists its keys too) | ✓ | ✓ |
| `/clear` | Terminal: starts a new chat. VS Code: clears the transcript on screen | ✓ | ✓ |
| `/compact` | Summarises the earlier part of the chat to save context; the whole chat stays in History | ✓ | ✓ |
| `/save [name]` | Saves the chat | ✓ | |
| `/resume <name or number>` | Continues a saved chat | ✓ | |
| `/history` | Saved chats: list them, read one (`/history <n>`), `/history delete <n>` | ✓ | |
| `/search <query>` | Searches past turns | ✓ | ✓ |
| `/copy` | Terminal: the whole chat, to select and copy. VS Code: copies the last reply | ✓ | ✓ |
| `/export` | Saves the conversation to a Markdown file | | ✓ |
| `/exit` | Terminal: quits (asks first if the chat is not saved). VS Code: closes the panel | ✓ | ✓ |

## Long tasks

| Command | What it does | Terminal | VS Code |
|---|---|:---:|:---:|
| `/fix <bug>` | Finds and fixes a bug | ✓ | ✓ |
| `/debug <issue>` | Debugs an issue to its root cause | ✓ | ✓ |
| `/refactor <change>` | Refactors without changing behaviour | ✓ | ✓ |
| `/hunt <area>` | Hunts for real bugs, each proved by a failing run | ✓ |✓ |
| `/task <goal>` | Runs a long task; `/task` alone shows it; also `resume`, `review`, `discard`, `budget` | ✓ | |

In the terminal app, `/fix`, `/debug`, `/refactor`, `/hunt` and `/task` run as long tasks with their own budget. In VS Code, `/hunt` does too; `/fix`, `/debug` and `/refactor` are single prompts there, which continue by themselves in Auto. `/task` and `/provider` are in the terminal app only. See [Long tasks](/features/long-tasks).
