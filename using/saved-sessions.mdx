## Whose chat is whose

Since 1.6.0:

- **The terminal app and VS Code no longer share a chat.** Each has its own chat, its own saved chats (`/history`, `/resume`), its own search and its own "new chat". Your code index, saved rules and spending limits are still shared, because they belong to the project.
- **Each terminal window has its own chat.** What you ask in one is not in the other's history, and `/clear` or `Ctrl+N` in one leaves the other alone. Saved chats are the terminal's, so a chat you `/save` in one window is in the other's `/history`.
- **Each launch of the terminal app starts a new chat.** Closing the terminal and opening it again starts an empty chat. `/save` a chat you want to come back to, then `/resume` it.
- **VS Code windows** open on the same folder still share one chat.

A chat left behind by a terminal window that was closed is removed once nothing has been said in it for seven days.

<Note>
  **Coming from 1.5 or earlier?** The chat that was current becomes the VS Code panel's. Every chat you saved is copied into both lists, so nothing you saved disappears from either. The terminal starts with an empty chat.
</Note>

## Save a chat

```text
/save
/save my-name
```

A chat can be saved once it has a question and an answer. Saving the same chat again after more work updates its saved copy. An update only adds to it.

## Find and continue a chat

| Command | What it does |
|---|---|
| `/history` | Lists the saved chats, numbered |
| `/history <n>` | Reads saved chat `n` |
| `/resume <n>` | Continues saved chat `n` |
| `/resume` | Lists the saved chats, as `/history` does |
| `/history delete <n>` | Deletes saved chat `n` |

`<n>` is the chat's number in the list, or the name you saved it under. Case does not matter. To read or continue a chat, the start of its name is enough if it fits only one chat. To delete one, give the whole name.

In the list, `⚠` marks a chat whose last answer did not finish, or whose spec still has open criteria.

## Start a new chat, or quit

`/clear` and `Ctrl+N` start a new chat in this window. If the chat on screen is not saved, Mochiii asks first: `This chat is not saved. Save or clear?`

| Key | What it does |
|---|---|
| `s` | Saves the chat, then starts a new one |
| `c` | Starts a new one. This chat is not saved |
| `Esc` | Keeps the chat |

Quitting a chat you have not saved asks too: `This chat is not saved and will be erased. Save or quit?`

## What is kept, and where

Each saved chat is one gzipped file. It holds the chat's name, if you gave one, its first and last question, when it started and ended, how many turns it has, the active spec if there was one, whether the last answer was cut off, and each turn.

The files are in `~/.local/state/mochiii/history/`, in a folder for each project, with one folder inside it for each client: `terminal` for the terminal app and `vscode` for the VS Code panel. See [Settings and file locations](/reference/settings-and-files).

## Limits

- At most **50** saved chats for each project in each client. Past that, the oldest are removed.
- At most **20 MiB** for all saved chats together, across every project and both clients. Past that, the oldest are removed.
- At most **8 MiB** of text in one saved chat. A chat larger than that is not saved.

When a save removes older chats, Mochiii says so. A chat you bookmark in the VS Code panel (the star) is never removed, and does not count toward these limits. To remove every saved chat, delete the `history` folder.
