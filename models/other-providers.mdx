Mochiii knows 17 providers; for most of them it tells the provider from the key itself and sends the key to that provider only.

*Describes terminal app 1.6.1 and VS Code extension 1.0.2, which works with terminal app 1.6.1 or later.*

## How a key is recognised

- **A prefix only one provider uses** (`sk-or-`, `sk-ant-`, `nvapi-`, …): the key goes to that provider.
- **A bare `sk-`**, which OpenAI, DeepSeek, Moonshot and DashScope all use: the key is sent nowhere until you say whose it is. Pick the provider from the list, or type `/connect deepseek` (any name from the table).
- **No prefix** (Mistral, SambaNova, Z.ai): pick the provider first.

A key is only ever sent to the provider that issued it. Pick Groq and paste a key that starts with `nvapi-`, and it is checked with NVIDIA; the screen says so.

## Models

For every provider but OpenRouter, connecting asks the provider which models it serves and tries them until one answers; `/model` then lists that provider's models. Models the provider says are not there are left out, and ones that sent nothing back stay, marked as such.

See [Choosing a model](/models/choosing-a-model).
