Paste an Anthropic key, which starts with `sk-ant-`, and Mochiii sends your questions to Anthropic.

*Describes terminal app 1.6.1 and VS Code extension 1.0.1, which works with terminal app 1.6.1 or later.*

| | |
|---|---|
| Address | `https://api.anthropic.com/v1` |
| Key | starts with `sk-ant-` |
| Name for `/connect` | `anthropic`, or `claude` |

## Connect

<Steps>
  <Step title="Get a key">
    Create an API key in your Anthropic account.
  </Step>
  <Step title="Open the provider list">
    In the terminal app type `/provider` (or `/connect`); in VS Code type `/connect`. Pick **Anthropic**, or **Any key** to let Mochiii tell the provider from the key.
  </Step>
  <Step title="Paste the key">
    The key is asked for in a masked box, never as an argument. Mochiii checks it with Anthropic before it stores it; a key Anthropic refuses is not stored.
  </Step>
  <Step title="Pick a model">
    For any provider but OpenRouter, connecting asks Anthropic which models it serves, finds one that answers, and `/model` then lists Anthropic's own models.
  </Step>
</Steps>

The key is sent to Anthropic and to no other provider. See [Choosing a model](/models/choosing-a-model) for switching models and checking which key is in use.
