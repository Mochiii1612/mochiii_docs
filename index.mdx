Mochiii is an AI coding agent that knows your codebase, in VS Code and in your terminal. It reads your project, answers questions about it, writes and fixes code, runs your tests, and works through long tasks.

These pages describe version 1.6.0, of both the terminal app and the VS Code extension.

<Note>
  Mochiii is in beta. It works and is used daily, but some features and docs are still being finished. Expect changes between versions. Please report bugs to supportmochiii@gmail.com.
</Note>

## What you need to use it

- **A model.** Mochiii asks a language model to answer. You give it an API key from a model provider, or you point it at a model server running on your own computer. See [Connect a model](/getting-started/connect-a-model).
- **A project folder.** Mochiii works on the folder it starts in. Start it inside a project, not in your home folder.

## Code search

Mochiii indexes your project on your machine and finds the code that matters for each question. The index updates as you save, so answers match the code you have now. On first run in a folder, the terminal app asks whether to build the index. The index is kept in the `.mochiii/index` folder inside the project.

## MCP servers

You can add MCP servers to give Mochiii more tools. See [Add an MCP server](/mcp/add-a-server).
