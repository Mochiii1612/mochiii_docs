Mochiii is an AI coding agent that knows your codebase: it reads your project, answers questions about it, writes and fixes code, runs your tests, and works through long tasks, in VS Code and in your terminal.

*Describes terminal app 1.6.1 and VS Code extension 1.0.1, which works with terminal app 1.6.1 or later.*

## What you need

- **A model.** Mochiii asks a language model to answer. Give it an API key from a model provider, or point it at a model server on your own computer. See [Choosing a model](/models/choosing-a-model).
- **A project folder.** Mochiii works on the folder it starts in, or the folder open in VS Code.

## What it does

- **Knows your codebase.** It indexes your project on your machine and finds the code that matters for each question. See [How indexing works](/features/indexing).
- **Edits you can check.** Every edit passes the same checks and is backed up. In VS Code you choose how much it asks: see [Modes](/using/modes).
- **Long tasks and specs.** `/fix`, `/debug`, `/refactor` and `/hunt` work through a whole job; `/spec` builds to a written spec. See [Long tasks](/features/long-tasks) and [Specs](/features/specs).
