With the web tools, the agent can search the web and read pages; an answer that used them ends with the pages it read.

*Describes terminal app 1.6.1 and VS Code extension 1.0.1, which works with terminal app 1.6.1 or later.*

## Where they are on

| | `web_search` and `web_fetch` |
|---|---|
| Terminal app, a provider's model | On, and they run without asking |
| Terminal app, a model on your computer | Off until `/web on` (and `/agent on`) |
| VS Code extension, a provider's model | On: **Manual** asks before each call, **Auto** runs them without asking |
| VS Code extension, a model on your computer | Off |
| A long task (`/fix`, `/debug`, `/refactor`, `/hunt`, `/task` in the terminal app; `/hunt` in VS Code) | Not used |

Set either tool to `ask` in [models.json](/reference/models-json) to see every call before it is sent, or to `deny` to turn it off. In VS Code, point `mochiii.configPath` at a `models.json` of your own to change the bundled settings.

<Warning>
  A web search sends text to a third party over the internet. Secret-shaped values are stripped from the query before it leaves, and an address carrying one is refused, but other text the agent has read is not, so an instruction planted in a file or a page can make a call carry it.
</Warning>

## What it can and cannot reach

- Addresses on your local network, link-local addresses and cloud-metadata addresses are refused.
- Fetched pages reach the model fenced as untrusted data, which it may quote but never obey.
- Mochiii cannot vouch for the far end.

## The sources under an answer

{/* SCREENSHOT GAP: a Sources block. Web tools are off for a local model; not run. */}

An answer that used the web ends with the pages it read, listed by Mochiii itself:

```text
Sources (pages read for this answer):
- gov.uk — <https://www.gov.uk/...>
- en.wikipedia.org — <https://en.wikipedia.org/wiki/...>
```

It says *read*, not *used*: Mochiii knows which pages it handed the model, not which sentence came from where. At most five, addresses only, never page titles. The list is part of the saved answer.
