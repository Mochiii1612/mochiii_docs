`/team` runs one question through specialists in turn, by default a researcher and then a coder, instead of a single agent.

*Describes terminal app 1.6.1 and VS Code extension 1.0.2, which works with terminal app 1.6.1 or later.*

```text
/team why does checkout round the total twice?
/team:planner,coder add a VIP30 discount code
```

- `/team <question>` uses the researcher, then the coder.
- `/team:a,b <question>` names the specialists, in order. The roles are `planner`, `researcher`, `coder` and `tester`.

`/team` works in both clients.

## When it is worth it

In Mochiii's own evaluation, `/team` passed 24 of 28 tasks against a single agent's 23 of 28: one task ahead, at 1.5 times the tokens and 2.3 times the time. Use it when one more solved task is worth that cost. A researcher-then-coder team also beat planner-then-coder (24 of 28 against 22 of 28).
