Mochiii comes as a VS Code extension and as a terminal app. Install either, or both.

## Where each one runs

| System | Terminal app | VS Code extension |
|---|---|---|
| Linux x64 | Yes | Yes |
| Linux ARM64 | Yes | No |
| macOS, Apple Silicon | Yes | Not yet |
| Windows x64 | Yes | Yes |
| Windows on ARM | Yes, the x64 build under Windows' emulation | No |

Intel Macs are not supported: the engine that runs the code-search model has no Intel Mac build.

## The VS Code extension

Install **Mochiii** from the [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=MochiiiAIAgent.mochiii-vscode), or from a terminal:

```bash
code --install-extension MochiiiAIAgent.mochiii-vscode
```

Click the lotus icon in the Activity Bar, paste an API key when asked, and start asking. See [VS Code](/using/vscode).

## The terminal app

You need [Node.js](https://nodejs.org) 18 or later, which includes npm. The same command works on every system:

```bash
npm install -g mochiii
```

npm installs the `mochiii` package and the one platform package that matches your computer. On Linux, the regular build needs glibc for code search; on a system that uses musl, such as Alpine, npm installs a build **without code search**.

Check that it worked:

```bash
mochiii --version
```

Then go to a project folder and start it:

```bash
cd path/to/your/project
mochiii
```

If `mochiii` is not found in the terminal you installed from, open a new terminal. The first start in a folder asks a few questions: see [First run](/getting-started/first-run).

## Update

<Warning>
  Update the terminal app and the VS Code extension together. The first new version to open Mochiii's chat memory upgrades it, and an older version cannot use it after that. See [Troubleshooting](/troubleshooting#i-updated-one-client-and-chats-stopped-saving).
</Warning>

The terminal app:

```bash
npm install -g mochiii@latest
```

Then run `mochiii -stop` in each folder you use the terminal app in, and reload VS Code.

## Stop and remove

Mochiii runs a background service for each project folder you use it in. In each folder you used, run:

```bash
mochiii --stop
```

Then remove the package:

```bash
npm uninstall -g mochiii
```

## If it does not start

If `mochiii` says the package for your computer is not installed, run `npm install -g mochiii` again. The `mochiii` package depends on a separate package for each platform, and your install is missing the one for your computer.
