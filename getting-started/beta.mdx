title: "Beta"
description: "What beta means for Mochiii, where to report bugs, and what is not supported yet."
---

Mochiii is in beta: it works and is used daily, but some features and docs are still being finished, so expect changes between versions.

*Describes terminal app 1.6.1 and VS Code extension 1.0.2, which works with terminal app 1.6.1 or later.*

## Report a problem

- **Bugs and requests:** supportmochiii@gmail.com
- **Security problems:** mochiiijuly@gmail.com, and nowhere else.

With a bug report, include your system, which client and its version (`mochiii --version`, or the version in VS Code's Extensions view), what you did, what happened, and the lines from the log. The logs are in `~/.local/state/mochiii/logs/`; in VS Code, run **Mochiii: Show Daemon Log**. Logs can contain file paths from your project, so check them before you send them.

## Not supported yet

- The VS Code extension on macOS, or on ARM computers. Use the terminal app there.
- Remote SSH, WSL and Dev Containers in VS Code.
- Intel Macs, in either client.
